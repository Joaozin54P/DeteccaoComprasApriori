# Detecção de Compras Suspeitas com Apriori

## Descrição
Projeto desenvolvido em Python para identificar compras fora do padrão utilizando limites de quantidade e conceitos inspirados no algoritmo Apriori.

## Funcionalidades
- Cadastro do cliente
- Compra de passagens
- Compra de itens de mercado
- Compra de salgados
- Verificação de limites por categoria
- Análise de padrões baseada no algoritmo Apriori
- Geração de alertas para compras suspeitas

## Tecnologias
- Python 3
